# Career Wrapped 2026 — concept prototype

An interactive prototype built for **Operation 10 Lakh**, my growth-strategy submission to *The Lakhpati Internship — Think like a Growth Hacker* (Unstop, 2026).

> **Not an official Unstop product.** All names, numbers, percentiles and opportunities shown are illustrative sample data.

## What it shows
- **Journey A, existing users:** consent → your year → a shareable 9:16 recap card with an archetype → share sheet with a personal referral link.
- **Journey B, new students:** a 2027 goals card → 60-second sign-up to save it.
- **Tracking panel:** the analytics events each step would fire (`card_generated`, `share_clicked`, `signup_completed`, `first_action`).

## Run it
It is a single static file with no build step. Open `index.html` in any browser, or host it on GitHub Pages.

## Tech
Plain HTML, CSS and JavaScript. Fonts: Anton, Poppins and Inter (Google Fonts).
